# Suchmaschinen: Lernumgebung Digitale Medien, Jahrgang 6

Wie Suchmaschinen funktionieren, gute Suchbegriffe finden, Werbung und Fake News erkennen.

Die Lernumgebung läuft direkt im Browser, ohne Anmeldung und ohne Installation.

**Direkt starten:** https://herr-brandt.github.io/dm6-suchmaschinen-oer/
